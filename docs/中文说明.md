# swagent — 中文说明

一个 **MCP 服务器**，让 AI 通过 COM 驱动本机安装的 SOLIDWORKS：草图、拉伸、旋转、打孔、
阵列、镜向、抽壳、倒角、出工程图、存盘、导出、截图——并且**每个建模动作都返回实测数值**。

```
MCP 客户端  ──stdio JSON-RPC──▶  swagent  ──comtypes/COM──▶  SLDWORKS.exe
                                      │
                                      └─ 每步量体积，没变化就报错
```

## 为什么自己写

现成的 SolidWorks MCP 服务（`solidworks-mcp`、`mcp-server-solidworks`、`solidworks-agent`）
基本都假设 SOLIDWORKS 已经在运行、只支持较新的版本，而且**建模失败时照样返回成功**。
这个项目的前提是：模型要能自己判断“这一步到底做成了没有”。

## 实测到什么程度

只在一台机器上验证过：Windows 11 + SOLIDWORKS **2022 SP05** + 中文界面 + 校园网络许可。

| 能力 | 实测数据 |
| --- | --- |
| 100×60×20 长方体 | 体积 120000 mm³ |
| ⌀12 通孔 | 去料 2261.947 = π·6²·20 |
| 盲孔（成型到下一面） | 只切一层壁，去料 2261.947 |
| 沉头孔 ⌀16×6 + ⌀8 | 去料 1910.088，与解析值一致 |
| 旋转（传动轴） | 1010273.366 mm³，与解析值完全相同 |
| 24 齿渐开线齿轮 | 62484.6 mm³，解析 62644.8（−0.256 %，齿顶用弦） |
| 8 孔传动轴 | 985643.279 mm³，解析 985643.279（**−0.000 %**） |
| 装配 / 工程图 / 配置表 | 2 个零件；A0 图纸 4 个视图；15000 / 30000 mm³ |

## 安装

```bat
git clone https://github.com/<your-account>/swagent.git
cd swagent
python -m venv .venv
.venv\Scripts\pip install -e .
.venv\Scripts\python tests\test_offline.py     :: 15 项离线检查，不需要 SOLIDWORKS
```

接到 MCP 客户端（例如 DeepSeek Harness）：

```yaml
- id: mcp-solidworks
  name: '@deepseek-ai/dsh-mcp-client'
  config:
    serverName: solidworks
    transport: stdio
    command: 'D:\path\to\swagent\.venv\Scripts\python.exe'
    args: ['-m', 'swagent']
    toolCallTimeoutMs: 600000
```

## 三条设计原则

1. **量了再说**：每个建模调用前后各量一次体积，没变化就抛 `cut_failed` / `extrude_failed`。
   这条规则抓出过 `FeatureExtrusion2` 返回了对象却没建特征的情况。
2. **写盘白名单**：只能写包目录和它的父目录，可用 `SWAGENT_OUTPUT_ROOTS` 追加；
   越界返回 `path_not_allowed` 并附上允许的目录。
3. **错误是对象**：`{"code": "not_connected", "message": …, "hint": "先连上许可服务器所在的
   网络或 VPN，再调用 sw_status"}`，而不是一堆调用栈。

## 硬约束与坑

完整清单见 [PITFALLS.md](PITFALLS.md)，最影响使用的几条：

- 这台机器上 VBA 7.1 只对**管理员进程**初始化，非管理员时保存会“成功”但写 0 字节。
- 校园网络许可：VPN 没连上时 `sw_status` 会直接给出诊断，而不是卡在弹窗上。
- 切割必须来自**面**草图，并且调用 `FeatureCut3` 时草图仍处于编辑状态。
- 盲孔用 `through_next` 比给深度可靠。
- 旋转体上的面，草图和零件坐标不同源——先把法兰拉伸出来打孔，再旋转轴身。

## 已知不足

- 参数个数是按 2022 的类型库量的，换年份可能多一个或少一个参数。
- `sw_add_mate` / `sw_linear_pattern` / `sw_drawing_annotations` 已接线但没实测。
- 不支持曲面、钣金、焊件、仿真、CAM。
